使用方法：

2. 在支持 front matter 的 Markdown / Astro / 博客项目中使用笔记。
3. 自绘训练配方 SVG 是本地资源，可离线显示。
4. 论文原图通过 RT-2 与 OpenVLA 官方站点的 HTTPS 链接引用；查看这些图需要网络。
5. 若博客需要离线托管所有图片，请根据 Markdown 内的原图链接下载并修改路径。

图文资料来源及原作者署名见 Markdown 的“参考资料与图片来源”。
